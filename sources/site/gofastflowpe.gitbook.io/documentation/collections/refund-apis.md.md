Markdown versions of documentation pages are available by appending \`.md\` to page URLs; this page is available as \[Markdown\](https://gofastflowpe.gitbook.io/documentation/collections/refund-apis.md). # Refund APIs FastFlowPe offers following refund APIs: \* \*\*Initiate Refund\*\* – Creates a refund request for a previously successful PayIn transaction. Upon successful validation, the API returns a unique refund \`transaction\_id\` that can be used to track the refund. \* \*\*Check Refund Status\*\* – Retrieves the latest status of a previously initiated refund using its refund \`transaction\_id\`. This API allows merchants to verify whether the refund has been successfully processed or has failed.

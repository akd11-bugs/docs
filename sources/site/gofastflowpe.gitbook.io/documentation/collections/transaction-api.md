The FastFlowPe provides the following APIs:

- **Initialize PayIn** – Initiates a new payment transaction and returns a unique `transaction_id` along with a `checkout_url` that can be used to redirect the customer and complete the payment.

- **Check Transaction Status** – Retrieves the current status of a previously initiated payment transaction using the associated `transaction_id`. This API allows merchants to verify the outcome and details of the transaction.

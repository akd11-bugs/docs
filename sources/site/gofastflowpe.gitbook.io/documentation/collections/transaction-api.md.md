Markdown versions of documentation pages are available by appending \`.md\` to page URLs; this page is available as \[Markdown\](https://gofastflowpe.gitbook.io/documentation/collections/transaction-api.md). # Transaction API The FastFlowPe provides the following APIs: \* \*\*Initialize PayIn\*\* – Initiates a new payment transaction and returns a unique \`transaction\_id\` along with a \`checkout\_url\` that can be used to redirect the customer and complete the payment. \* \*\*Check Transaction Status\*\* – Retrieves the current status of a previously initiated payment transaction using the associated \`transaction\_id\`. This API allows merchants to verify the outcome and details of the transaction.

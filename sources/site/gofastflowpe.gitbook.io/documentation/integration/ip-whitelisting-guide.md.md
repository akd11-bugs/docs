Markdown versions of documentation pages are available by appending \`.md\` to page URLs; this page is available as \[Markdown\](https://gofastflowpe.gitbook.io/documentation/integration/ip-whitelisting-guide.md). # IP Whitelisting Guide Each merchant can register a Primary and optional Secondary IP. Every X-API-Key is bound to these IPs, and FastFlowPe validates that requests originate only from them—rejecting all others. This ensures leaked keys cannot be misused from unauthorized locations. You can add IPs via \*\*Merchant Dashboard → Settings → API\*\*. \\ \*\*Notes:\*\* Once submitted, IPs cannot be changed, you may choose to set only a Primary IP or both.
